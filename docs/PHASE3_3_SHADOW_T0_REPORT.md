## Exact Requests Sent

Safe, non-destructive requests were sent through the public authoritative route:

```bash
curl -sk -D - https://mcp-hugo.arleo.eu/.well-known/oauth-authorization-server -o /dev/null
curl -sk -D - 'https://mcp-hugo.arleo.eu/authorize?response_type=code&client_id=bad&redirect_uri=https://claude.ai/callback' -o /dev/null
curl -sk -D - -X POST https://mcp-hugo.arleo.eu/token \
  -H 'Content-Type: application/x-www-form-urlencoded' \
  --data 'grant_type=authorization_code&client_id=bad&client_secret=bad&code=dummy&redirect_uri=https://claude.ai/callback' \
  -o /dev/null
curl -sk -D - -X POST https://mcp-hugo.arleo.eu/register \
  -H 'Content-Type: application/json' \
  --data '{"redirect_uris":["https://claude.ai/callback"]}' \
  -o /dev/null
```

Observed responses:

- metadata: `200`
- authorize invalid request: `400`
- token invalid request: `401`
- register request: `201`

No valid token was issued and no valid authorization was created.

This is the proof that mirrored traffic is reaching audited Go OAuth paths.
